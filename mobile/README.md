# App Flutter — Vise SMA

Cliente do aluno (Android + Web), local-first com Drift/SQLite e sync em lote.

## Rodar

Backend precisa estar em `http://localhost:8000` (ver README da raiz).

```bash
flutter pub get
flutter run -d chrome   # web
flutter run             # android
```
